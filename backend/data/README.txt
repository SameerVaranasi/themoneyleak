BUSINESS — THE MONEY LEAK
Synthetic educational dataset created for DATATHON. It is not real company data.
Files: customers.csv (3,000), products.csv (250), transactions.csv (18,000), inventory.csv (5,000), campaigns.csv (1,200).
Join keys: customers.customer_id = transactions.customer_id; products.product_id = transactions.product_id / inventory.product_id; campaign data can be analyzed by date/channel/category.
Important: costs/prices are independently generated and may create unrealistic margins. Teams should profile the data, flag inconsistencies, and document assumptions before making recommendations.
